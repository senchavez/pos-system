# CodeIgniter POS System

A basic four-page Point-of-Sale website built using CodeIgniter 4. This project demonstrates routing, controllers, views, navigation, and displaying static PHP array data using `foreach` loops.

## Pages

- `/` - Landing page
- `/about` - About page
- `/customers` - Customer accounts
- `/users` - User and staff accounts

## Technologies Used

- PHP 8.2
- CodeIgniter 4
- HTML
- CSS
- Composer

## Project Setup

1. Clone or download the repository.
2. Open a terminal inside the project folder.
